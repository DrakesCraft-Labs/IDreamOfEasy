# Procedencia

Este repositorio es una adaptación a Paper/Purpur 1.21.11 de:

    https://github.com/SlimefunGuguProject/IDreamOfEasy

Autor original: **Bunnky**
Licencia original: **GPL-3.0**

La licencia se conserva sin modificar. Al ser GPL, esta adaptación se distribuye bajo los mismos
términos.

El addon se publica también en https://blob.build/project/IDreamOfEasy, que enlaza a
`github.com/Bunnky/IDreamOfEasy` — un repositorio que a fecha de esta adaptación devuelve 404.

Los cambios de DrakesCraft son de compatibilidad y de seguridad: paquetes de Slimefun al core
Drake, Java 21, `paper-api` 1.21.11, renombres de la API de Bukkit, candados de arranque
retirados y autoactualizador fuera. El contenido y las mecánicas son de su autor.

Si eres el autor y prefieres que retiremos esta adaptación, escríbenos y se quita.
